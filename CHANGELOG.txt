SENETECH SETUP - HISTORIQUE STABLE
==================================

Version 1.5.1 - Base Stable
---------------------------
- V1.5.1 devient la base Stable officielle.
- Branche main reservee aux versions validees.
- Branche develop reservee aux nouvelles modifications et tests.
- Ajout de Parametres pour choisir Stable ou Developpeur.
- Le choix du canal est memorise localement.
- Modes Portable et Installe dans une seule application.
- Ajout du telechargeur public SENETECH-Download.cmd.
- Nettoyage des anciens fichiers de distribution incomplets.
- Mise a jour depuis V1.4.3 maintenue via GitHub.

Version 1.5.0
-------------
- Ajout du mode Installe en complement du mode Portable.
- Installation possible dans Program Files avec raccourcis et desinstallation.
- Verification automatique des mises a jour en mode Installe.

Version 1.4.3
-------------
- Premier test reel de mise a jour depuis GitHub valide depuis V1.4.2.
- Telechargement, verification, remplacement et redemarrage testes.

Version 1.4.2
-------------
- Ajout du bouton Mise a jour.
- Verification GitHub de la version disponible.
- Nettoyage des fichiers temporaires.
- Optimisation du cache hors ligne.

Version 1.3

- Logo et identite visuelle SENETECH.
