SENETECH SETUP V1.5.1 - VERSION STABLE
=======================================

SENETECH est une application de preparation, diagnostic et maintenance legere pour Windows 10 et Windows 11.

VERSION OFFICIELLE
------------------
Version : 1.5.1.0
Canal : Stable
Branche : main
Modes : Portable + Installe

COMMENT RECUPERER SENETECH
--------------------------
Methode 1 - ZIP complet :
1. Recuperer le ZIP officiel SENETECH V1.5.1 FULL transmis par SENETECH.
2. Cliquer sur Extraire tout.
3. Ouvrir le dossier extrait.
4. Lancer SENETECH-Setup.exe.

Methode 2 - Telechargeur GitHub :
1. Recuperer SENETECH-Download.cmd.
2. Lancer le fichier.
3. La version Stable est telechargee dans le dossier Telechargements\SENETECH-Setup.
4. SENETECH se lance automatiquement une fois les fichiers prepares.

Aucun compte GitHub n'est necessaire pour utiliser SENETECH ou recevoir les mises a jour.

IMPORTANT
---------
Ne telechargez jamais un ancien SENETECH-Setup.exe isole depuis l'historique du depot. SENETECH utilise plusieurs fichiers runtime.

Le telechargeur officiel et le ZIP complet s'occupent de fournir tous les fichiers necessaires.

PORTABLE / INSTALLE
-------------------
Mode Portable : SENETECH fonctionne dans son dossier ou depuis une cle USB.
Mode Installe : le meme SENETECH peut etre installe sur le PC avec raccourcis et desinstallation.

STABLE / DEVELOPPEUR
--------------------
Stable : recommande pour les utilisateurs et les PC vendus.
Developpeur : versions de test destinees au developpement avant validation.

Le canal peut etre choisi dans Parametres a partir de V1.5.1.

MISES A JOUR
------------
SENETECH consulte GitHub automatiquement. Lorsqu'une nouvelle version est disponible, il peut la telecharger et l'appliquer sans que l'utilisateur ait besoin d'ouvrir GitHub.

SUPPORT
-------
En cas d'erreur de mise a jour, le journal technique se trouve dans :
%TEMP%\SENETECH-Update.log
